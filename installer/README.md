# 📦 Windows Installer

The Inno Setup script installs the main executable and diagnostic for the current Windows user, with Start menu shortcuts, optional desktop shortcut and an uninstaller. No elevation or additional drivers are required. Startup remains user-controlled in Settings.

The script uses the original icon generated by build.rs. The explicitly selected GitHub release job supplies AppVersion and AppIcon, packages the setup executable and attaches its SHA-256 checksum alongside the portable executable.

The installer must be smoke-tested on Windows for install, upgrade, shortcut launch, and uninstall. The uninstaller removes the startup registration only if it points to this installation; battery history and preferences are intentionally retained in the local data folder.

Official tool: [Inno Setup](https://jrsoftware.org/isinfo.php).

No installer binary is produced until the release build is explicitly requested.
