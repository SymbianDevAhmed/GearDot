# 📦 Windows Installer

The Inno Setup script installs the main executable and diagnostic for the current Windows user, with Start menu shortcuts, optional desktop shortcut and an uninstaller. No elevation or additional drivers are required. Startup remains user-controlled in Settings.

The script uses the original icon generated by build.rs. The explicitly selected private-package or release job supplies AppVersion and AppIcon, packages the setup executable and attaches its SHA-256 checksum alongside the portable executable.

The installer must be smoke-tested on Windows for install, upgrade, shortcut launch, and uninstall. The uninstaller removes the startup registration only if it points to this installation; battery history and preferences are intentionally retained in the local data folder.

Official tool: [Inno Setup](https://jrsoftware.org/isinfo.php).

Private packaging uploads both the Setup EXE and portable ZIP to GitHub Actions without creating a Release. The portable ZIP contains portable.flag and PORTABLE.txt (as README.txt); its writable data directory is created on first launch. Only an explicit release request publishes a Release.

The packages include the bundled W.D.B.M and HeadsetControl executables.
Run `installer/get-headsetcontrol.ps1` before packaging to obtain the pinned
Windows helper and its corresponding source.
