# 📦 Windows Installer

The EXE uses the standard NSIS wizard and the MSI uses Windows Installer dialogs. Both let you choose an installation folder and launch GearDot at the end. Run the same setup again to repair or uninstall the installed version. Setup installs for the current Windows user and creates a Start menu shortcut.

The packaging job builds the MSI with WiX and the EXE with NSIS, using the icon generated by build.rs. The EXE writes its Windows Installer log to `%TEMP%\GearDot-Setup.log`. Run it with `/S` for an unattended install and check its process exit code.

The installer must be smoke-tested on Windows for install, upgrade, shortcut launch, and uninstall. The uninstaller removes the startup registration only if it points to this installation; battery history and preferences are intentionally retained in the local data folder.

Private packaging uploads the Setup EXE, MSI, and portable ZIP to GitHub Actions. The portable ZIP contains `portable.flag` and `PORTABLE.txt` (as `README.txt`). Its data directory is created on first launch. Only an explicit release request publishes a Release.

The packages include the bundled W.D.B.M and HeadsetControl executables.
Run `installer/get-headsetcontrol.ps1` before packaging to obtain the pinned
Windows helper and its corresponding source.
