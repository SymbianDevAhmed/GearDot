# Changelog

## 1.0.0

- Show battery readings for supported mice, keyboards, headsets, earbuds, and controllers.
- Customise the Windows notification area, taskbar readings, and screen-edge battery slider.
- Configure low-battery and full-charge alerts, per-device visibility, and device profiles.
- Detect devices via Windows APIs and bundled BatteryHub, W.D.B.M, and HeadsetControl readers.
- Provide a copyable diagnostics report and Windows x64 Portable, EXE, and MSI packages.
